# Token and icon provenance

The token exports are unchanged copies of the canonical OpenChamber design resources from the original host checkout. The accompanying OpenChamber license applies to those resources. The JSON export retains its original source metadata.

The seven icons are unchanged licensed SVG assets from the same source inventory. Their names are pencil-ai, search, list-indefinite, send-plane-2, close, arrow-down-s, and fullscreen. The Remix Icon license applies.

The extension uses only the required copies. It does not import the host application's stylesheet, design guide, source, or backend. The original application's design authority stays in that application.

The presentation adapter converts the three fixed token rules into picker-owned selectors. It does not modify the copied token values. The package checks must verify both source identities and selector containment.
